三步开始

  1. 下载并双击安装包。
  2. 按 Windows 安全提示确认安装；CampusAI 不会要求关闭 Defender 或 SmartScreen。
  3. 双击桌面的 CampusAI，等待主页面自动打开。

当前 Pilot / Release Candidate 安装器没有 Authenticode 签名，可能显示“未知发布者”。请只使用本页下载，并核对 SHA-256。

Privacy

项目数据保存在当前电脑的用户目录。CampusAI 不包含 API Key、不启用 telemetry，默认卸载不会删除项目数据。DeepSeek Key 不随安装器提供，只能由用户在本机显式配置。

Known limitations

  • 仅支持 Windows 10/11 x64。
  • 基础安装不包含约 500+ MiB 的增强语义模型；基础 lexical retrieval 可直接使用。
  • 固定使用本机端口 3000 和 8000；端口冲突时启动窗口会给出提示。
  • 未签名测试构建可能触发 SmartScreen；不会绕过 Windows 安全机制。
